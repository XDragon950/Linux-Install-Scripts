These are scripts to install a bunch of packages and change aspects of the system in different linux distrobutions.
# To Install On 
## Debian:
```
  sudo apt install git
  git clone https://github.com/XDragon950/Linux-Install-Scripts
  cd Linux-Install-Scripts
  sudo chmod +x debian.sh
  ./debian.sh
```
## Arch
```
  sudo pacman -S git
  git clone https://github.com/XDraogon950/Linux-Install-Scripts
  cd linux-install-scripts
  sudo chmod +x arch.sh
  ./arch.sh
